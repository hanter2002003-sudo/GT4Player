# GT4 Player

تطبيق أندرويد مخصص للعبة **Gran Turismo 4** فقط.

## ما الموجود في المشروع

| الجزء | الحالة |
|---|---|
| واجهة رئيسية مرتبة (اختيار BIOS، اختيار ISO، زر اللعب) | جاهز |
| فحص حقيقي لملف ISO: يقرأ SYSTEM.CNF ويقبل GT4 فقط (أمريكا / أوروبا / اليابان) | جاهز |
| تحكمات لمس متعددة اللمسات: مقود يمين/يسار + دواسة بنزين + دواسة فرامل + START + إيقاف مؤقت | جاهز |
| وضع «تجربة التحكمات» لتجربة اللمس بدون لعبة | جاهز |
| **محرك محاكاة PS2** (`libps2core.so`) | **غير مرفق** |

## لماذا المحرك غير مرفق؟

محاكاة PS2 (المعالج Emotion Engine، وحدتا VU، معالج الرسوميات GS) مشروع ضخم عمل عليه فريق PCSX2 سنوات، ولا يمكن كتابته من الصفر ضمن محادثة. التطبيق هنا هو **الغلاف المخصص لـ GT4**، والمحرك يُركَّب تحته عبر واجهة JNI واضحة:

1. ابنِ أو احصل على محرك PS2 مفتوح المصدر لـ arm64 مع جسر JNI يطبّق الدوال الست الموجودة في `docs/native_bridge_template.cpp`.
2. سمِّ الناتج `libps2core.so` وضعه في `app/src/main/jniLibs/arm64-v8a/`.
3. أعد بناء التطبيق، وسيظهر في الشاشة الرئيسية «✓ المحرك مثبّت».

> ترخيص: PCSX2 مرخّص GPL-3.0. إذا دمجت شيفرته في تطبيقك فيجب نشر تطبيقك مفتوح المصدر بنفس الترخيص.

## البناء

1. ثبّت **Android Studio** (إصدار حديث).
2. `File ▸ Open` واختر مجلد `GT4Player`، وانتظر مزامنة Gradle.
3. وصّل هاتفك (تفعيل USB debugging) واضغط **Run**.

لم أستطع بناء المشروع واختباره هنا (لا يوجد Android SDK في بيئتي)، فقد تحتاج إصلاح خطأ أو خطأين صغيرين عند أول بناء.

## ما تحتاجه لتشغيل اللعبة

- **ملف BIOS** لـ PS2 مستخرج من جهازك.
- **ملف ISO** للعبة GT4 من قرصك الأصلي.
- هاتف قوي (معالج فئة Snapdragon 8 أو ما يعادله) لتشغيل سلس.

## ربط التحكمات

التطبيق يرسل للمحرك القيم التالية كل ~8 مللي ثانية:

- `steer` من -1 إلى +1 ← العصا اليسرى (المحور X)
- `gas` من 0 إلى 1 ← ضغط تناظري على زر X (البنزين في GT4)
- `brake` من 0 إلى 1 ← ضغط تناظري على زر المربع (الفرامل في GT4)
- `buttons` ← قناع بتات (`START` وغيره)

يرتفع البنزين تدريجياً خلال ~140 مللي ثانية ليحاكي الضغط التناظري. عدّل القيم في `GameActivity.kt` (دالة `ramp`).

## إضافة نسخة GT4 أخرى

أضف رقم القرص في `Gt4IsoValidator.kt` داخل `KNOWN`. الأرقام الحالية: `SCUS-97328` و`SCES-51719` و`SCPS-17001`.
